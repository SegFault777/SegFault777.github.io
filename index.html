SEGFAULT777 / MINIDAW / MAIN

MINIDAW

A DAW for all of us.

MiniDAW is a lightweight, fast digital audio workstation for Windows, built with Qt 6 and inspired by the workflow of Logic Pro. It stays approachable for beginners and still offers what a producer expects.

Download GitHub
01 / THE PROJECT

A DAW for all of us.

One Windows program for arranging, recording, editing and mixing: a multitrack arrangement, MIDI editing, built-in instruments, VST3 plug-ins, tempo and time-signature tracks, time stretching, automation and bouncing.

02 / WHAT'S INSIDE

Arrangement, instruments and mixing.

ARR

Arrangement

A multitrack Tracks area with a time-signature ruler, a smart snap grid, cut / copy / paste of regions, cycle range, metronome and undo / redo.

MIDI

MIDI editing

Piano roll, a 16-step sequencer, Standard MIDI File import and export, MIDI keyboards and Musical Typing, plus Logic-style functions such as quantize, arpeggiator and humanize.

SYN

Instruments

A 16-voice subtractive synthesizer, a synthesized drum kit and Drummer with styles, variations and fills.

MIX

Mixer and effects

Channel strips with EQ, compressor, echo, reverb, overdrive, chorus and filter, two aux sends, a master limiter and volume, pan and send automation.

VST3

Plug-ins

VST3 instruments and effects with their own editor windows, saved state, and a small plug-in SDK for writing your own effects.

FILE

Projects and bounce

.mdaw projects with autosave and crash recovery, Loop Browser, bounce to 16 / 24-bit or 32-bit float WAV, and five interface languages.

03 / BUILD & RUN

Build it from source.

build.sh
# clone and build the Qt version
$ git clone https://github.com/SegFault777/MiniDAW.git
$ cd MiniDAW
$ export QT_DIR=C:/Qt/6.8.3/msvc2022_64
$ ./build.sh            # build/MiniDAW.exe
$ ./build.sh installer  # installer-out/MiniDAW-<version>-setup.exe

# run the DSP unit tests (no Qt needed)
$ bash tests/run.sh
Requirements: Windows 10/11, Visual Studio 2022 or newer, Git Bash, Qt 6.5 or newer (6.8 recommended). Inno Setup 6 is optional, for the installer. Set VST3_SDK_DIR to include VST3 hosting.
